PvZ Toolkit Dx —— 第三方组件与许可说明 (THIRD-PARTY-NOTICES)
================================================================================

本项目 PvZ Toolkit Dx 基于 PvZ Toolkit（原作者 lmintlcx，GPL-3.0，
https://github.com/lmintlcx/pvztoolkit）；本修改版由 SilenceWoods 维护，
并同样以 GNU GPL-3.0 发布（全文见仓库根目录的 LICENSE）。
再发布必须保留原作者署名、以 GPL-3.0 继续开源并提供完整对应源码。

本文件列出本项目用到的第三方组件、各自的用途、许可名称、版权行，以及
**仓库内该许可全文所在的位置**（下文路径都相对仓库根目录）。
除"待确认"两条外，本文中的许可文本都是从仓库里的许可文件**原样摘录**的。

本仓库有两个可执行目标，用到的组件并不完全相同：

  * pztk_imgui.exe   —— 现行主程序（Dear ImGui + GLFW + OpenGL3）
                        构建：env/scripts/build_imgui_demo.cmd
  * pztk_hook.dll    —— 注入 DLL（MinHook）
                        构建：env/scripts/build_hook_dll.cmd
  * pvztoolkit.exe   —— 旧版 FLTK 前端
                        构建：env/scripts/build_toolkit.cmd
                        （本仓库的构建脚本已不再担保它的哈希，见 BUILD.md）

"用于"一栏里的 M 表示 pztk_imgui.exe，H 表示 pztk_hook.dll，
F 表示 pvztoolkit.exe。

12. "待确认"清单（查过哪些路径）
================================================================================

(a) HDE 32（Hacker Disassembler Engine 32），第 7 节
    查过：
      * tool-src/hook/minhook/hde32.cpp:1-6   —— 只有版权行，无条款
      * tool-src/hook/minhook/hde32.h:1-10    —— 同上
      * tool-src/hook/minhook/table32.h:1-6   —— 同上
      * 全仓库搜索名为 LICENSE / LICENSE.* / LICENCE / COPYING /
        COPYING.* / NOTICE 的文件，tool-src/hook/ 下**一个都没有**
      * tool-src/hook/minhook/ 目录列表：只有 .cpp / .h 源码，没有许可文件
    结论：许可名称与条款正文在仓库里查不到 —— 需向上游 MinHook / HDE 项目
          确认后再补全此条。

(b) MinGW-w64 / GCC 运行库（静态链入三个产物），第 11 行总表
    查过：
      * env/mingw32/ 根目录列表：bin、i686-w64-mingw32、include、lib、
        libexec、share、mingwvars.bat、version_info.txt —— **没有**许可文件
      * 通配搜索 env/mingw32/**/COPYING*  → 0 个结果
      * 通配搜索 env/mingw32/**/*icen*   → 只有
        env/mingw32/share/cmake-4.4/Templates/CPack.GenericLicense.txt
        （那是 CMake 自己的模板，与本项目无关）
      * env/mingw32/version_info.txt —— 只说明这是 winlibs personal build
        gcc-16.2.0-mingw-w64msvcrt-14.0.0-r2（GCC 16.2.0 / MinGW-w64 14.0.0），
        没有许可信息
    结论：工具链副本被裁剪掉了许可文件，本机查不到 —— 需从 winlibs 发行包
          或 GCC / MinGW-w64 官方仓库确认后再补全此条。
    链接方式（可自行核对）：env/scripts/build_imgui_demo.cmd 的
      -static -static-libgcc -static-libstdc++；
      pztk_imgui.exe 的导入表里没有 libstdc++-6.dll / libgcc_s_dw2-1.dll，
      说明这两个运行库是静态链进去的。

13. 运行时依赖（随系统提供，本项目不分发）
================================================================================
以下东西被调用但**不在**本仓库/发布包里，因此不涉及再分发：

  * Windows 系统库：kernel32 / user32 / gdi32 / advapi32 / ole32 /
    shell32 / comdlg32 / winmm / crypt32 / wintrust / dwmapi / shcore /

    glfw3.a 里，找不到就跳过）

    没有把字体文件打进 exe，也没有随包分发
  * 游戏本体：Plants vs. Zombies（PopCap）—— 本工具只读写其内存，不包含
    也不分发任何游戏文件
