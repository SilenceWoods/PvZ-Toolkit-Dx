================================================================
  植物大战僵尸辅助工具（PvZ Toolkit Dx）—— 使用说明
================================================================

----------------------------------------------------------------
一、这是什么
----------------------------------------------------------------

这是一个面向《植物大战僵尸》一代电脑版的免费辅助工具。它可以：

  * 直接在游戏里改阳光、金币、智慧树高度、选卡、植物与僵尸；
  * 阵型代码的读取、复制、粘贴与一键布置；
  * 设置出怪方式与出怪种类，查看每一波出怪的数量统计；
  * 调整僵尸移动速度、植物攻击速度、植物看到僵尸后的反应时间；
  * 改变游戏运行速度、更换背景音乐；
  * 执行智慧树指令
  * 解包 / 打包游戏的 PAK 资源文件。

本工具是开源项目 PvZ Toolkit（原作者 lmintlcx，GPL-3.0 协议）的增强版，
核心功能来自原版，本增强版主要新增了：
  * 僵尸移速 / 植物攻速 / 首发延迟（前摇）三个可精确调整的功能；
  * 女仆秘籍
  * 魅惑、冻结僵尸 / 无视僵尸进家
  * 「多倍出怪」/「N倍僵尸血量」;
  * 「高级暂停」;
  * 智慧树指令控制、可视化;
  * 一套全新的界面。

本工具完全免费，请勿购买或转售。


----------------------------------------------------------------
二、支持的游戏版本与运行环境
----------------------------------------------------------------

【游戏版本】
  主要面向英语原版 1.0.0.1051及其汉化版本。
  这个版本上所有功能都能用。其他语言、其他版本的游戏，工具也能连上，
  但有一部分功能会直接显示「未生效 / 未命中」，并且【不会】去改动游戏
  （这是故意设计的安全行为，不是坏了）。
  移速、攻速、首发延迟这些基础功能对原版支持的全部正式版本都有效。

【系统环境】
  * Windows 系统（本程序是 32 位程序，32 位与 64 位 Windows 都能运行）。
  * 主程序需要与配套文件 pztk_hook.dll 放在【同一个文件夹】里。
    缺少它、或者两者的版本不配套时，首发延迟等功能不会生效
    （界面上会明确写出来）。这两个文件请成对使用，不要单独替换其中一个。
  * 建议把工具放在有写入权限的普通文件夹里（例如桌面、游戏目录、D 盘自建
    目录）。不要放在 C:\Program Files 这类受保护目录，否则解包输出文件、
    保存出怪列表等操作可能失败。


----------------------------------------------------------------
三、快速开始
----------------------------------------------------------------

1. 把 pztk_imgui.exe 和 pztk_hook.dll 放在同一个文件夹里。

2. 启动游戏，再启动本工具。【顺序无所谓】 —— 先开工具、后开游戏也可以，
   工具每秒都会重新寻找游戏，找到后会自动连上。

3. 看窗口左上角的徽章：
       「已连接」          = 已经连上游戏，修改会立刻写进游戏
       「未找到游戏窗口」  = 还没连上（原因见第五节）

4. 连上以后【不需要】再点任何「启动 / 加载」按钮，工具会自动准备就绪。
   帧级功能会在界面上自己报告状态，例如「DLL已生效」「DLL未生效」。

5. 关闭工具即可。工具退出（甚至被强制结束）时，游戏里的一切改动都会
   自动收拾干净，不需要手动卸载，也不会把游戏留在被修改的状态里。


----------------------------------------------------------------
四、各页面功能说明
----------------------------------------------------------------

左侧一栏是页面切换按钮：战场 / 资源 / 阵型 / 关卡设置 / 杂项。
下面按页面说明。凡是没有特别说明的开关，都是【点一下立刻生效】、
再点一下取消。

================================
4.1 战场
================================

【卡槽】
  把一个选卡槽位的植物换成你想要的植物。
  做法：选「第 N 格」→ 选植物 → 点「换卡片」。勾上「模仿者」则换成该
  植物的模仿者版本。
  什么时候生效：只有在【选卡界面或战斗中】才有效（在主菜单点没有反应）。
  战斗中点 = 立刻生效；选卡界面点 = 工具先把这一格记下来，等你按 "Let's Rock"
  战斗正式开始那一刻再写进卡槽（游戏本来会用选卡结果覆盖卡槽，只能在那一刻写；
  只写你点过的格，不会覆盖你自己在选卡界面选的卡）。

  * 「取消必选卡片」（冒险模式二周目）：二周目开局戴夫会先替你选好 3 张卡，
    勾上它就能取消这个预选 —— 在选卡界面勾 = 那 3 张立刻能点掉 / 换掉；
    在别处勾 = 进关卡时根本不抽卡。本版不支持时界面显示"未生效(不支持此版本)"，
    并且**一个字节都不改**（不动游戏文件、不动存档）。

  * 「卡片冷却时间」（默认 = 「开启」）= 正在冷却的种子卡上会显示它还剩几秒
    （一位小数，例如 2.4），就绪后数字消失。两张不同冷却的卡一起转时，
    一眼就能看出哪张先好。它只是显示，不改游戏行为。数字画在卡面的
    标题条以下、阳光费用之间居中（含 2px 目测校准）。
    同一行会显示状态：「关闭」/「补丁已打上」/「未生效」/「待注入 DLL」。
    注：它需要 pztk_hook.dll，所以放在同一文件夹、
    两个文件版本配套才会生效。

【放置与清除】
  * 第一行：选「第几行」+ 植物 + 点「种植物」，可勾「模仿者」。
    行/列选「所有行」「所有列」就是整行 / 整列 / 全屏批量种满。
  * 第二行：选「第几列」+ 僵尸 + 点「出僵尸」。
  * 第三行：「冒墓碑」「搭梯子」「放钉耙」—— 在你选的行列放上对应场地物品。
  * 第四行：先在左侧选对象（植物 / 僵尸 / 梯子 / 墓碑 / 钉耙），再点「清除」。
  * 第五行：先在左侧选动作（启动 / 删除 / 恢复），再点「小推车」。
  什么时候生效：同样只有在【选卡界面或战斗中】才有效。
  注意：
    * 玉米加农炮（[47]）占两格宽，游戏规则上不种在第 9 列，工具会照此处理。
    * 「模仿者」会真的生成模仿者版本，效果和游戏里的一致。

【植物修改】六个开关
  植物无敌 / 植物脆弱 / 立刻装填 / 只投黄油 / 蘑菇睡醒 / 核弹无坑。
  「立刻装填」= 加农炮炮弹用完立刻装填。
  「核弹无坑」= 毁灭菇爆炸后不留下弹坑。

【僵尸修改】
  第一、二行五个开关：
    僵尸无敌 / 僵尸虚弱 / 停滞不前 / 冰车无痕 / 丑椒不爆
    * 「停滞不前」= 场上的僵尸原地不动。
    * 「冰车无痕」= 让冰车僵尸【根本不产生冰道】。这一点很重要：冰道会
      妨碍种植，只是把冰藏起来不叫无痕。详见第五节的已知副作用。
      已知副作用：开启时【不会】刷新出雪橇小队 —— 按游戏自己的规则，
      这个僵尸只能沿着冰道出现，而没有冰道正是「冰车无痕」想要的结果。
    * 「丑椒不爆」= 小丑僵尸和辣椒僵尸不爆炸。
  第三行：
    * 「暂停刷怪」= 停止继续刷出新的僵尸。
    * 「无视僵尸进家」= 僵尸走到门口就自己倒下，不用等它吃脑子。
  第四行：
    * 「魅惑当前僵尸」/「冻结当前僵尸」= 对【当前场上已有的】僵尸各生效一次。
      按下后按钮右侧会给出结果提示。
  第五行：
    * 「女仆秘籍」= 用下拉菜单控制舞王僵尸的相位，四个选项：
        关闭
        保持前进（舞王一直前进）
        跳舞（舞王不前进且不会召唤舞伴）
        召唤伴舞（舞王不前进且一直尝试召唤舞伴）
      选择后右侧会显示「已开启 / 已关闭」。

【其他修改】六个开关
  免费用卡 / 随意放置 / 无缝传送 / 连续铲子 / 清除浓雾 / 罐子透视。
  * 「随意放置」= 植物可以种在平时不能种的格子上（水面、屋顶、被其他植物占用的格子等）。
  * 「无缝传送」= 传送带无延迟。
  * 「连续铲子」= 铲子可以连续使用，不用每次重新拿。
  * 「罐子透视」= 罐子里的内容直接可见。

【底部的两个按钮】
  「僵尸移速 ...」「植物攻速 ...」会各打开一个独立的小窗口。

  >> 僵尸移速窗口
     * 左上表格：勾选 + 分类名称 + 合法区间 + 数值。勾上才会生效，
       数值可以直接打字输入，越界会自动按区间收回来。
     * 右侧：实时监测器，列出当前场上每一只僵尸的编号、种类与速度。
     * 左下：固定值分类的说明（这些分类的速度游戏里是写死的，不可调）。
     * 底部：「恢复默认值」按钮。
     * 说明：工具只固定每一发的随机抖动，不改写游戏定义表里的固定值。
       「速度值仅代表动画播放速度，同值不一定同速度。」
       冰车（冰车僵尸）的速度是按位置插值的：离房子越近越慢
       （0.25 → 0.10）；固定后会变成匀速前进。

  >> 植物攻速窗口
     * 分两块：「攻击间隔」和「首发延迟」。
       「攻击间隔」= 每次攻击之间的等待时间。
       「首发延迟」= 植物看到僵尸后到打出第一发之间的反应时间。
     * 右侧是实时监测器，左下是说明。
     * 首发延迟的下限是 0.01 秒（= 1 帧），精度也是帧级的。
     * 为了让首发延迟精确到帧，工具需要一个配套组件在工作；窗口左下角会
       显示「DLL已生效」或「DLL未生效」。显示「未生效」时首发延迟会退回
       精度较差的方式（下限放宽到 0.01 秒），其余功能不受影响。
     * 由于游戏机制，双发、裂荚、猫尾草的反应时间不同于其他射手；本工具
       可以让它们不丢弹。杨桃的首发延迟不改（它的索敌机制太特殊）。

================================
4.2 资源
================================

* 阳光（0 ~ 9990）、金币（0 ~ 99999）、智慧树高度（0 ~ 1000）。
  改完数值后，点右侧的「应用」按钮或按回车才会写入游戏。
* 「解除阳光上限」= 阳光可以超过游戏正常上限。
* 「自动收集」= 阳光、金币等自动收集，不用手点。
* 「不掉战利品」= 僵尸死亡后不掉落物品。
* 「花肥无限」「杀虫剂无限」「树肥无限」「巧克力无限」= 对应的消耗品
  数量不再减少。
* 未连接游戏时，所有修改都不会写入。


================================
4.3 阵型
================================

【快捷布阵】
  * 「快捷布阵模式」不是一个普通开关，而是一个「一键准备」：
    勾上后会【强制打开】六项便利功能（自动收集 / 免费用卡 / 植物无敌 /
    立刻装填 / 暂停刷怪 / 清除浓雾），并把战场页与资源页上对应的勾选框
    锁住；取消勾选时，会恢复成你原来的勾选状态。
  * 「智能搭梯」= 先清空场上所有梯子，再给每一个「模仿者南瓜头」所在的
    草地格自动铺上梯子。

【场地】
  * 「重置场地」= 按下面选中的场景重置当前场地。
  * 场景下拉：白天 / 黑夜 / 泳池 / 雾夜 / 屋顶 / 月夜。
  * 「铺睡莲」「摆花盆」：左边的下拉用 ■/□ 图案表示列的预设范围
    （■ = 该列种满），选中后点右侧按钮即按这个范围铺开。
  * 底部会显示「游戏当前场景」。

【阵型代码】
  * 「加载阵型列表文件 (***.yml)」= 手动导入一个阵型列表文件。
  * 中间的下拉列出当前场景可用的阵型。
  * 下面的代码框是【只读】的，请用按钮操作：
      获取代码 = 读取当前场上阵型
      复制导出 = 把代码框内容复制到剪贴板
      粘贴导入 = 从剪贴板读入并规范化
      布置阵型 = 按代码在场上种满

  >> 关于 .yml 阵型列表文件（重要）
     把 .yml 文件放在【程序同目录】下，工具启动时会自动加载；
     也可以启动后用「加载阵型列表文件」按钮手动导入。
     文件格式要求：
       * 编码必须是 UTF-8；
       * 第一行必须是（原样、英文标点）：
             #! pvztoolkit
       * 从第二行起，每一行表示一条阵型，格式是：
             "阵型名称": 阵型代码
         冒号后面必须有一个空格；阵型名称必须用英文双引号括起来，
         阵型代码不加引号；
       * 空行、以及以 # 开头的行是注释，会被忽略；
       * 格式错误的行会被跳过（不影响同一文件里的其他行）；
       * 阵型名称建议只用中英文和数字，尽量别用特殊符号。
     一个文件里可以写多条阵型，程序同目录下的多个 .yml 文件会一起加载。

================================
4.4 关卡设置
================================

【出怪方式】
  * 三种模式，【三者都只使用你在下面「僵尸种类」里勾选的那些种类】：
        自然 = 游戏自己生成出怪
        极限 = 均匀填充僵尸直到达到出怪上限
        模拟 = 按权重随机填充僵尸直到达到出怪上限
  * 「红眼权重」（1000 ~ 6000）：只在「模拟」模式下可以调。
  * 「11~19 波不含红眼」：只在「极限 / 模拟」模式下可以调。
  * 板块下方有一个应用按钮，按钮文字会随模式变化（「自然出怪 (游戏生成)」/
    「极限出怪 (均匀填充)」/「模拟出怪 (加权随机)」）；点它才会按当前设置
    生成出怪列表并写入游戏。
  * 「出怪详情 ...」打开出怪数量统计窗口。
  * 「多倍出怪」：把游戏自己的出怪点数预算乘 N 倍（1 ~ 24，1 = 关闭，
    默认就是 1 = 关闭）。【只在「自然」模式下可以调】。
    挑哪种僵尸仍然由游戏自己决定。注意：
      - 固定刷出的僵尸（旗帜波先塞的普通僵尸、新僵尸的介绍、末波的巨人、
        末波的补齐全种类）不参与倍增；
      - 每波仍然受 50 只的上限限制，所以在高波数时可能看不出明显变化。
  * 注意：出怪修改只在【「选卡界面」或「战斗中」】生效，
    在主菜单、图鉴、商店等界面不会写入游戏。

【出怪数量统计窗口】
  在「关卡设置」页点「出怪详情 ...」打开。
  * 「刷新」读当前关卡的出怪列表。
  * 「保存 .zbl」把列表导出成文件；「加载 .zbl」读入并（若当时在选卡
    界面或战斗中）写进游戏。
  * 两个页签：「数量统计 (33 种 x 20 波)」按种类和波数显示数量与合计；
    「原始列表 (1000 项)」显示 20 波 × 50 槽的原始内容。
  * 「显示数量为 0 的种类」可以展开完整表格。

【僵尸种类】
  * 20 个勾选框（4 列 × 5 行）选择允许出现的僵尸种类。
  * 「清空已选」清掉全部勾选；「应用」按当前设置生成出怪列表。
  * 普通僵尸与旗帜僵尸不在这个勾选列表里 —— 它们是游戏出怪的基础，
    工具会自动把它们算进去（极限 / 模拟模式下还会保证旗帜僵尸存在）。
  * 「僵尸血量倍数」：1.00 = 原版。只影响之后新出现的僵尸；
    改回 1.00 会把已经改过的僵尸一起还原。

【关卡】
  * 模式下拉（73 项）：冒险模式、各种生存模式、小游戏、解谜等。
  * 关卡下拉（1-1 ~ 5-10）：【只有选「冒险模式」时才有意义】，
    其它模式下这一项是灰的。
  * 「混乱关卡」= 按上面选的模式（和关卡号）把当前关卡换成指定关卡。
    只有在选卡界面或战斗中有效。
  * 「无尽轮数」= 设置无尽模式的轮数（仅无尽模式有效）。
  * 「直接过关」= 直接结束当前关卡。只有在关卡内有效。
    在生存 / 无尽这类模式下，工具会自动等到一个合适的时机再结算，
    避免影响回合计数。
  * 「通关存档」= 解锁所有奖杯（同时解锁小游戏、生存、解谜、
    商店里的大部分内容）。
    警告：这个功能会【改写你的游戏存档内容】，建议先自己备份一份存档
    （用杂项页的「存档文件夹」可以直接打开存档目录）。

================================
4.5 杂项
================================

【游戏】
  * 背景音乐：下拉选 12 首曲子之一，点「背景音乐」按钮切换。
  * 「存档文件夹」= 在游戏目录和几个常见位置里找到存在的那个存档目录并
    打开（支持 PopCap / Steam / Zoo / Reflexive 等常见安装方式）。
  * 「允许后台运行」（【默认已勾选】）= 游戏失去焦点时继续运行。
    如果关掉它，你一点修改器窗口游戏就会被暂停。
  * 「禁止存档删档」= 禁止游戏删除、覆盖你的存档。
  * 「显示隐藏页面」（【默认已勾选】）= 解锁游戏里的隐藏关卡。
  * 「高级暂停」= 把游戏自带的暂停（按空格）变成高级暂停：
      - 按空格不再弹出暂停对话框；
      - 音乐不停；
      - 鼠标、种植预览、选卡、种植、铲子、工具都能照常用；
      - 但整个世界连同特效一起冻住（粒子、掉阳光、池边闪光、僵尸、植物、
        子弹、刷怪、浓雾、关卡结束判定）。
      再按一次空格继续。
      下方会显示状态：「已生效 · 当前: 暂停中 (再按空格继续)」或
      「已生效 · 当前: 运行中 (按空格暂停)」。
      橙色提示：「若按空格没反应, 先点一下游戏画面(键盘焦点必须在游戏里)」。

【变速】
  * 下拉可选 10x / 5x / 2x / 1x / 0.5x / 0.2x / 0.1x，点「变速」生效。
    x 越大越快（10x 最快，0.1x 最慢）。游戏原本是 1x。
  * 右侧会显示当前的毫秒/帧。改完立刻生效，对当前这次游戏运行有效。

【智慧树指令】
  * 每一项都是一个勾选框，勾选 = 向游戏发送一次对应的按键序列
    （和你自己在关卡里手敲一模一样），再点一次取消。
  * 发完指令后工具会回读游戏状态核对：
      显示「(已生效)」= 确实生效了；
      显示「(未生效)」= 没有生效，工具会自动取消该勾选。
  * 有三个指令需要智慧树高度分别达到 1000 / 500 / 100 才有用
    （可以在「资源」页设置智慧树高度）。

【PAK 解包 / 打包】
  * 第一行两个按钮：
      「选择pak文件」选择要解包的游戏 PAK 文件；
      「选择输出/输入目录」选择目录。
  * 「解包」：需要在上面选好 【pak 文件】 和 【输出目录】，点解包即把
    pak 内容解到输出目录里。
  * 「打包」：只需要选好 【输入目录】，点打包后输出文件会【自动生成】在
    输入目录的上一级目录里（即与 pak 同级的位置），文件名形如
    main_<时间戳>.pak，不需要自己指定文件名。
  * 处理过程中会显示「处理中, 请稍候 ...」，完成后弹窗告诉你结果和
    输出位置；出错也会弹窗说明原因。
  * 建议先备份原 pak 文件。

【关于】
  * 「文档」= 打开本文件（使用说明.txt）。它必须和主程序放在同一个目录，
    否则会提示找不到。
  * 「关于 ...」= 显示发行版本号、编译时间、原版项目信息、作者与许可。
  * 下方一行显示版本号与「核心层复用 lmintlcx 原版 (GPL-3.0)」。


----------------------------------------------------------------
五、常见问题
----------------------------------------------------------------

■ 一直显示「未找到游戏窗口」
  1) 确认游戏已经启动并进入了主界面（只启动了启动器/登录器不算）。
  2) 确认是受支持的游戏版本（见第二节）。改过窗口标题、加过壳的版本工具
     可能认不出来。
  3) 试试右键修改器「以管理员身份运行」再连一次。
  4) 有些杀毒软件 / 安全软件会拦截工具读写游戏内存，导致连不上或功能
     失灵。把工具目录加入白名单后重试。
  5) 工具每秒会自动重试一次，不用重启工具；但游戏换进程（关掉重开）后，
     建议在游戏进入主界面后稍等一两秒。

■ 点了按钮没反应
  1) 先看左上角是不是「已连接」。
  2) 很多功能只在你【已经进入关卡】时才动作：种植物、出僵尸、换卡片、
     混乱关卡、无尽轮数、直接过关，都需要处于选卡界面或战斗中。
     在主菜单点它们不会有任何反应。
  3) 阳光 / 金币 / 智慧树高度这类数值，改完必须点右侧「应用」或按回车
     才会写入。
  4) 出怪相关的修改只在选卡界面或战斗中生效。

■ 高级暂停按空格没反应
  1) 【先用鼠标点一下游戏画面】。键盘焦点必须在游戏里；只要点了修改器
     窗口，焦点就跑到工具上了，这时按空格完全没有反应 —— 这是正常现象，
     不是功能坏了（界面上有一行橙色提示）。
  2) 确认「高级暂停」已经勾上，并且状态行显示「已生效」。
  3) 游戏窗口最小化时按空格也不会有反应。

■ 阵型名字里出现问号
  界面字体只会预先准备「程序同目录下的 .yml 文件」里出现过的汉字。
  所以：
    * 需要显示生僻字的 yml，请放到【程序同目录】，然后【重启工具】；
    * 如果是在工具启动之后才用「加载阵型列表文件」按钮临时导入的，
      那个文件里的生僻字可能显示成问号（功能不受影响，阵型照样能布置）。

■ 功能不生效的可能原因
  1) 版本相关：冰车无痕、女仆秘籍、多倍出怪、高级暂停这些
     功能目前是在英语原版 1.0.0.1051 上验证的。在别的版本上，工具会
     如实显示「未生效 / 未命中 / 已回退」，并且宁可不用也不会乱改游戏。
  2) 配套文件问题：pztk_hook.dll 缺失、和主程序不在同一目录、或者两者
     版本不配套时 ——
       首发延迟会退回到精度较低的方式（下限仍为 0.01 秒）；
     请成对使用同一次构建出来的两个文件。
  3) 时机问题：出怪 / 种植物 / 出僵尸 / 换卡片一类的修改，只在选卡界面
     或战斗中生效；换关、重开游戏之后，有的设置需要重新点一次。
  4) 「冰车无痕」的已知副作用：开启期间该行【不会出现雪橇小队】。
     这是游戏自己的规则造成的（这个僵尸只能沿冰道出现），不是故障。
  5) 「无视僵尸进家」「僵尸血量倍数」只对之后出现的僵尸生效，场上已有的
     僵尸不追溯；「魅惑 / 冻结当前僵尸」则是按下时对当时场上的僵尸生效一次。
  6) 如果工具是在有写入保护的目录（如 C:\Program Files）里运行的，
     保存 .zbl、解包输出等写文件的操作会失败 —— 把工具挪到普通目录。
